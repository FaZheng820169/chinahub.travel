## 用户需求

修复全站页面在响应式视口（尤其是在 md 到 lg 尺寸屏幕之间）顶部导航栏存在的严重布局重叠问题（如 Logo 与链接、链接与按钮重叠）。

## 产品功能与效果

- 将导航栏链接部分的显示断点从 `md` 修改为 `lg`，并在 `lg` 尺寸下缩小间距与字号（使用 `lg:space-x-4` 和 `text-sm`），到 `xl` 尺寸恢复大间距。
- 保证导航项 `whitespace-nowrap` 防止意外换行。
- 将右侧按钮组（“Plan Your Trip”、语言切换）以及对应的汉堡菜单断点同步由 `md` 升级至 `lg`。
- 确保所有的 HTML 文件（根目录和多语言目录）同步生效。

## 技术选型

- 使用 Node.js 脚本批量查找并替换 HTML 中的类名（Regex String Replacement）。
- 利用现有的 Tailwind CLI 重新提取项目中的 class 并编译生成压缩版本的 `common.css`。

## 实现思路

1. **编写脚本**：创建 `scripts/fix-nav-spacing.js`。脚本递归遍历根目录以及 `es/`、`fr/`、`zh/` 目录下的 `.html` 文件。
2. **文本替换规则**：

- 导航链接容器：`hidden md:flex space-x-8` 替换为 `hidden lg:flex lg:space-x-4 xl:space-x-8 items-center font-medium text-[var(--text-secondary)] text-sm xl:text-base whitespace-nowrap`。
- "Plan Your Trip" 按钮：包含 `hidden md:block` 替换为 `hidden lg:block` 并追加 `whitespace-nowrap`。
- 语言切换容器：`hidden md:block` 替换为 `hidden lg:block`。
- 移动端汉堡菜单：`md:hidden` 替换为 `lg:hidden`。

3. **重新编译 CSS**：通过 `npm run build:css` 扫描 HTML 文件，使得新增的响应式类（如 `lg:flex`、`lg:space-x-4` 等）能够被打包进 `common.css` 中。
