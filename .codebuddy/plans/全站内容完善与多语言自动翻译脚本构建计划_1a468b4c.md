## 需求总结

为进一步完善 ChinaHub 项目的信息完整度和生产环境就绪度，执行全站查漏补缺和多语言自动化工程。

## 核心功能

1. **冗余清理**：删除根目录下已废弃无用的历史文件 `nav.html`。
2. **新增 FAQ 页面 (`faq.html`)**：

- 补充针对外国人的高频文化差异解答（如饮用水、小费文化、卫生间差异）。
- 补充经典防骗指南（如茶楼骗局、假和尚骗局等）。
- 复用现有网页的导航栏与底部结构，保持一致的视觉体验。

3. **新增 404 兜底页 (`404.html`)**：

- 设计带有统一品牌样式（Tailwind + 红色主色调）的 404 错误页。
- 包含导航、语言切换器及返回主页引导，避免死链流失。

4. **全站导航栏更新**：

- 遍历根目录下的所有主页面，在顶部导航（Navigation）和底部（Footer）添加 `faq.html` 的入口链接。

5. **Node.js 多语言自动化翻译脚本**：

- 编写 `scripts/translate.js` 脚本，基于 `cheerio` 解析 HTML。
- 提取页面中的文本节点，对接大语言模型 API（提供标准 OpenAI 接口配置项）进行自动化翻译。
- 翻译完成后，自动按目录结构（`es/`、`fr/`、`zh/`）输出更新多语言 HTML 文件，为后续长期维护和新增页面提供基建。

## 技术选型

- **前端页面**：HTML5 + Tailwind CSS (通过 CDN) + 自定义 CSS (共用 `common.css`)，保持无构建纯静态结构。
- **自动化脚本**：Node.js。使用 `cheerio` 解析和修改 DOM 树，使用 `dotenv` 管理环境变量，使用原生的 `fetch` 调用 AI 翻译接口（兼容 OpenAI 格式）。

### 实施细节

1. **翻译脚本策略**：脚本不仅需要翻译标签中的纯文本内容，还需要保留结构。最佳实践是提取带有标识的 HTML 片段进行大块翻译，或递归遍历翻译非空文本节点。同时脚本需处理 `<meta>` 标签描述及 `<title>` 的翻译。
2. **导航栏同步**：由于页面较多（十几个 HTML），将会使用正则替换或 AST 工具统一为所有文件加入 `FAQ & Scams` 链接。
