## 用户需求

用户反馈首页顶部的导航栏在部分宽度下依然存在挤压和重叠的情况（Logo与文本链接挤压，Contact与右侧按钮挤压）。

## 问题分析

当前导航栏包含了 7 个长文本链接、1 个多语言切换下拉菜单、1 个显眼的 "Plan Your Trip" 按钮以及左侧 Logo。即便之前将断点从 `md` (768px) 升级到了 `lg` (1024px)，并且缩小了间距，但在 1024px ~ 1280px（如 13 寸笔记本或 iPad 横屏）的显示器下，横向物理空间依然不足以塞下所有这些元素，导致相互覆盖。

## 解决方案与效果

将导航栏折叠为“汉堡菜单”的断点从 `lg` (1024px) 进一步提升至 `xl` (1280px)。

- **效果**：在屏幕宽度小于 1280px 时，网站会自动折叠为友好的移动端侧滑菜单，不再尝试把所有链接强行挤在一排，从根本上杜绝 UI 重叠问题。只有在真正的超大屏（>1280px）时，才显示横向展开的完整导航条。

## 技术选型与实现思路

1. **断点升级**：通过正则匹配将导航栏相关的 Tailwind 响应式类名由 `lg` 提升为 `xl`。

- `hidden lg:flex lg:space-x-4 xl:space-x-8` -> `hidden xl:flex xl:space-x-6`
- `hidden lg:block` (右侧按钮与多语言) -> `hidden xl:block`
- `lg:hidden` (汉堡按钮与移动端折叠面板) -> `xl:hidden`

2. **自动化更新**：编写 Node.js 脚本 `scripts/fix-nav-breakpoint.js`，精准扫描并修改全站所有 50 个 HTML 页面中与导航条相关的代码块，同时更新之前的注入脚本 `scripts/inject-mobile-menu.js` 以保持后续逻辑一致。
3. **重新编译 CSS**：更新 HTML 类名后，需执行 `npm run build:css` 使得 Tailwind 将新引入的 `xl` 相关 utility classes 打包入生产环境。
