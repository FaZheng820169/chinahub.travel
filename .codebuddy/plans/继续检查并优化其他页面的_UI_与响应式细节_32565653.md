## 产品概述

优化 ChinaHub 全站的响应式 UI 细节与组件一致性，解决移动端导航失效及页面底部信息断层的问题，提升全端用户体验。

## 核心功能

- 补全移动端菜单：全站新增响应式全屏“毛玻璃”下拉导航菜单，并实现汉堡按钮的唤起交互逻辑。
- 统一全局富页脚：修复子页面（如 Visa Guide、FAQ 等）页脚简陋与结构不一致的问题，将首页的四列完整富页脚同步至全站所有页面。
- 多语言深度覆盖：确保上述 UI 更新同步覆盖到 `es/`、`fr/`、`zh/` 目录下的所有网页。

## 选型与架构

- 自动化工具：Node.js 批量文本处理（Regex 替换与注入）
- UI 样式框架：Tailwind CSS (原生 CLI 编译)

## 实施策略

- **DOM 注入方案**：利用正则表达式精准定位 `</nav>` 结束标签，向后追加隐藏的移动端菜单 HTML；定位 `</body>` 前追加控制显隐的 `<script>` 逻辑代码。
- **跨端自适应**：移动端菜单默认添加 `fixed inset-0 z-40 hidden lg:hidden flex-col` 等响应式样式，配合 `backdrop-blur` 呈现毛玻璃效果。
- **模板替换方案**：提取 `index.html` 中的 `<footer ...>...</footer>`，将其作为模板批量覆盖其他几十个子页面的旧版 `<footer ...>...</footer>`，确保品牌展示和链接完全一致。
